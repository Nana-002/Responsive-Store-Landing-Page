Responsive Store Landing Page

A sleek, minimalist e-commerce landing page built with a mobile-first design approach.

Design Choices

Layout: Built using CSS Grid (`repeat(auto-fit, minmax(250px, 1fr))`) to handle the product layout. This ensures that the cards automatically stack into a single column on mobile screens and expand beautifully up to 4 columns on desktop displays without breaking.

Navigation:The header menu links dynamically adapt to screen widths, maintaining visibility across devices for an optimal user experience.

Typography & Palette: Chosen a crisp white and dark charcoal palette with high-contrast call-to-action buttons to ensure visual hierarchy and modern aesthetics.

Images: Scaled using fluid max-widths (`max-width: 100%`) so images never overflow their container boundaries on smaller mobile viewports.

Tested on mobile screens via Google Chrome DevTools device emulation.
